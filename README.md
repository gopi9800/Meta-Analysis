# Meta Ad Performance Analysis — Power BI Dashboard

## Overview

This project is a Power BI dashboard created to analyze Meta advertising performance across engagement, clicks, conversions, audience demographics, ad types, campaigns, and budget.

The dashboard helps evaluate how advertising campaigns perform across different audience and campaign dimensions.

## Business Questions

- How many impressions, clicks, engagements, and purchases were generated?
- What are the click-through, conversion, engagement, and purchase rates?
- How does ad performance vary by gender and age?
- How does click activity change by day, week, and hour?
- Which ad types generate higher engagement and clicks?
- How does performance vary across campaigns and target interests?
- How does advertising budget relate to campaign performance?
- How does performance vary across Facebook and Instagram?

## Dashboard Analysis

### Key Metrics

- Impressions
- Clicks
- Shares
- Comments
- Engagements
- Purchases
- Click-Through Rate
- Conversion Rate
- Engagement Rate
- Purchase Rate
- Total Budget
- Average Budget per Campaign

### Audience Analysis

The dashboard analyzes clicks by gender and age to understand audience engagement patterns.

### Time Analysis

Performance is analyzed across monthly, weekly, daily, and event-hour trends.

### Ad Type Analysis

Ad types are compared using metrics such as impressions, engagements, clicks, engagement rate, and click-through rate.

### Campaign & Platform Analysis

The dashboard provides campaign and target-interest filters and includes Facebook and Instagram performance.
